# ORBIT — Premium Calculator

A premium, responsive calculator with an amber/orange visual system and interactive Three.js 3D scene.

## Features
- Arithmetic operations, percentages, keyboard controls and history
- Responsive glassmorphism UI
- Dynamic 3D object reacting to calculator interactions
- No build step required
- Three.js loaded as an ES module from jsDelivr

## Run
Open `index.html` in a modern browser. For best results, serve the folder with any local static server.

## Stack
HTML + CSS + JavaScript + Three.js
